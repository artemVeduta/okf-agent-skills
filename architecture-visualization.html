GAP Trust Is Static
UUID from Git common dir. No trust rotation, no multi-party trust, no trust revocation. The trust model can only say "this is the same repo instance" - it cannot express "repo X trusts repo Y" or "trust was revoked".
GAP No Cross-Repo Safety
Federated workspace allows multiple repos but cross-repo write safety is unspecified. A write in repo A could reference concepts in repo B without safety guarantees.

GAP No Rollback
Post-write validation can fail but there is no undo/rollback mechanism. The publish step is atomic (write-via-temp + rename) but the semantic state after a failed post-write is unrecoverable without git.
GAP Derivative Maintenance
Index update and log append are marked as derivedEffects but the actual implementation of auto-maintained directory indices is unclear. What triggers an index rebuild?
GAP No Search Index
search() reads files on every call. No pre-built search index. At scale (500 files ceiling) this means O(n) full scan per search query.

14. Data Flow Summary

Key data flows through the system
Read Path
User → Skill MD → Wrapper stdin → protocol.parse → runtime.run → admission.admitRead → routing.resolve/read/search/enumerate → navigation → services.readFile → Response JSON → stdout
Write Path
User → Skill MD → Wrapper stdin → protocol.parse → runtime.run → executeBounded (11 gates) → validation.evaluate → services.publishFile → validation.postWrite → derivative updates → Response JSON → stdout
Orientation Path
Harness event → hooks.json → adapter-hook.js → logical cause → adapters.preClaim → adapters.claimAndDispatch → adapter-bridge → okf-read (orient) → runtime.orient → admission.completeness → result
Delegation Path
Main session → brief JSON → okf-delegate.js → delegation.validateBrief → spawnSync wrapper → worker agent executes → delegation.receipt() → okf-delegation/1 return
Router Path
User → okf SKILL.md → wrapper stdin (operation) → runtime.run (okf) → routerOwners[operation] → dispatch to leaf wrapper → leaf executes → response
Lifecycle Path
User (explicit) → okf-lifecycle SKILL.md → wrapper stdin (sync) → runtime.run → lifecycle.plan → abstained/revise/create → executeBounded (if not abstained) → response
