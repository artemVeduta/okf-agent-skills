# OKF Agent Skills

Cross-harness agent skills for maintaining lightweight
[Open Knowledge Format](https://okf.md/) documentation in software and
knowledge-only projects.

This project is in its research and specification phase. Its first release
will provide consistent OKF lifecycle behavior for Claude Code, Codex, and
OpenCode.

## Status

The architecture and developer workflow are being resolved through a public
Wayfinder issue map. Research findings will be published in this repository
with links to primary sources.
